Global Hospital Management System A full-stack Hospital Management System built with Spring Boot, MongoDB, HTML, CSS, and JavaScript. The application provides role-based workflows for patients, doctors, and receptionists. It is designed to digitize common hospital administration workflows while demonstrating the practical integration of custom Data Structures and Algorithms (DSA) in a real-world enterprise architecture.🚀 Project OverviewThe project separates the user interface from the REST API backend. The frontend communicates with the Spring Boot backend using HTTP requests and JSON payloads, while the backend stores application data in MongoDB.Custom DSA Implementations:Min-Heap: Priority queue for emergency appointment handling.Merge Sort: O(n log n) sorting for appointments (by date, patient name, or doctor fees).Insertion Sort & Binary Search: O(n²) worst-case preprocessing followed by O(log n) patient lookup by contact number.✨ Key FeaturesRole-Based Access: Dedicated dashboards and workflows for Patients, Doctors, and Receptionists.Patient Management: Registration, authentication, directory browsing, and search capabilities.Doctor Directory: Doctor registration, directory filtering by specialization, and availability tracking.Smart Scheduling: Appointment booking with automated doctor availability collision checking (15-minute window).Emergency Prioritization: High-priority queueing for emergency cases using a custom Min-Heap.Prescription Workflows: Doctor-generated prescriptions linked directly to patient appointment histories.Administrative Dashboard: Receptionist controls for system statistics, doctor management, and contact queries.🛠 Technology StackFrontend: HTML5, CSS3, Vanilla JavaScript, Font Awesome, Fetch API, Local StorageBackend: Java 21, Spring Boot 3.3.0, Spring Web, Spring Data MongoDB, MavenDatabase: MongoDB (Default port: 27017)Development Tools: Git, VS Code/IntelliJ, PowerShell, Modern Web Browser📂 System Architecture & Project StructureThe application follows a strict three-layer web architecture:Frontend: Presentation and browser-side interaction.Backend (Spring Boot): REST endpoints and business rules.Database (MongoDB): Repository-based persistence.PlaintextHospitalManagementSystem/

PatientAuthentication: Register with unique email/phone, login via email/password.Actions: Browse doctors by specialty, book appointments (with emergency toggle), view appointment history, cancel appointments, and print prescription receipts.2. Reschedule or cancel appointments. Review public contact queries.⚙️ Core Logic & Business RulesCollision Detection: New or rescheduled appointments are rejected if they fall within 15 minutes of an active appointment for the same doctor.Appointment Lifecycle:1 = Active0 = Cancelled (Excluded from collision checks)2 = Completed (Upon prescription creation)3 = Missed (Auto-flagged if older than 50 minutes without completion)Prescription Validation: Cannot be created before the scheduled appointment date.🔌 API DocumentationBase API URL: http://localhost:8080/apiAuthentication
